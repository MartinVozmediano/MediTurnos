# MediTurnos

Sistema de escritorio para gestionar turnos médicos, disponibilidad y priorización.

## Tecnologías

- Java 21
- Maven
- Java Swing
- SQLite
- JUnit 5

## Estructura

El código está organizado en modelo, vista, controlador, servicio y repositorio. La documentación se guarda en `docs/` y la base de datos en `database/`.

## Nota
Proyecto inicial preparado por el equipo para continuar el desarrollo en IntelliJ con Maven.
